# Ray Espinoza — Personal Portfolio Website

> This repository contains a personal portfolio website template built with HTML, CSS, and a Formspree-powered contact form. It is hosted via GitHub Pages.

---

## Contents
- `index.html` — Home / Intro and navigation
- `about.html` — Background, skills, and education
- `projects.html` — Project showcase with images and descriptions
- `resume.html` — Embedded PDF resume (loads automatically)
- `contact.html` — Centered stacked contact form (Formspree)
- `style.css` — Global styles and theme (dark theme)
- `RayEspinoza_UResume.pdf` — The actual resume PDF 
- `README.md` — This file

---
